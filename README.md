# C Complete Pack

A practical C learning repository covering the core language and common beginner/intermediate programming concepts.

## Topics covered

- Variables and data types
- Operators and expressions
- Control flow
- Functions and recursion
- Arrays and strings
- Pointers and dynamic memory
- Structs and unions
- File I/O
- Basic projects and simulation programs

## Build

You can compile each file individually:

```bash
gcc 01_basics/hello.c -o hello
./hello
```

Or build everything with CMake:

```bash
cmake -S . -B build
cmake --build build
```

## Project structure

- `01_basics/`
- `02_control_flow/`
- `03_functions/`
- `04_arrays_strings/`
- `05_pointers/`
- `06_structs/`
- `07_file_io/`
- `08_projects/`
